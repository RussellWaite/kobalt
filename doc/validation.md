# Native validation

Use the installed Qt 6.11.3 SDK. Configure once as described in [Building](building.md#mac). Run the commands below from `platforms/desktop/`. They use this checkout's code, assets and incremental cache. No device, firmware, Python or private service is required.

## Everyday commands

| Task | Build | Run or output |
| --- | --- | --- |
| Fast checks | `cmake --build --preset mac-fast-tests` | `ctest --preset mac-fast` |
| All native checks | `cmake --build --preset mac-tests` | `ctest --preset mac` |
| Integration checks | `cmake --build --preset mac-tests` | `ctest --preset mac-integration` |
| Screenshot gallery | `cmake --build --preset mac-screenshots` | `build/screenshots/mac/index.html`, relative to the repository root |
| Interactive app | `cmake --build --preset mac` | Open `build/desktop-mac/Kobalt.app` manually |

Use `ctest --preset mac -N` to list registered tests. Use `-R` to select a test name or `-L model`, `-L engine`, `-L session` or `-L desktop`, `-L resource` or `-L component`, `-L ui`, `-L platform` or `-L corpus` to select a group. CTest does not build tests automatically. A failed test prints its assertion and captured output. CTest keeps the latest run in `build/desktop-mac/Testing/Temporary/LastTest.log`.

## Test inventory

Two optional annotation benchmarks reuse the production Mac objects and stay outside the test presets. Build `kobalt-annotation-engine-benchmark` and `kobalt-annotation-gui-benchmark` from the configured desktop output. The engine executable accepts `--prepare BOOK FIXTURE` to select and validate 2,000 nonoverlapping passages from a supplied EPUB, then `--model BOOK FIXTURE OUTPUT` to measure endpoint resolution, visible-range filtering and page geometry. Its `--index BOOK FIXTURE OUTPUT` mode compares the retained source index with independent copies of the previous algorithms, including overlap queries, edits and changing drafts. The GUI executable accepts `BOOK FIXTURE COUNT OUTPUT [--sqlite] [--bookmarks]`, where COUNT is 0 to 2,000. It uses an isolated profile to measure reopening, twenty immediate forward turns, twenty backward turns with pending engine work drained before each turn outside timing, list first paint, list readiness, cached list reopening and deletion. It discards the first of six openings. It also measures wall time and process CPU time for 21 full and compact production store loads, visible-page excerpt batches, selected-record details and single-record edits. Compact SQLite records omit excerpts, chapter names and notes; JSON uses the same interface with its existing resident records. Fixture notes are optional and default to empty. SQLite runs separately measure a transactional import of both legacy lists and verify their original bytes. Bookmark runs record any merges caused by the chosen viewport rather than assuming every seeded position remains on a distinct page. Both require an explicit EPUB path; no external book is bundled. Keep fixtures, output and temporary directories under ignored `build/`. Run benchmarks sequentially without builds or other timed workloads. Record the build configuration alongside results. Debug Mac measurements do not establish Kobo latency or battery use. For fresh-process storage memory measurements, seed a new directory under this checkout’s `build/` with `--store-memory-seed FIXTURE COUNT DEST [--sqlite]`. Run `--store-memory ROOT full|compact OUTPUT` in separate processes. These modes measure retained payload units and process RSS without book layout, fixture parsing or bundled-font registration in the probe. RSS includes allocator and database state; it is not an exact allocation count.

## Temporary files and timing

All native checks and screenshot runs use private working and temporary directories under `build/desktop-mac/test-tmp/`. The CMake parent removes those directories after success, failure, signal termination or its timeout: 30 seconds for a check and 120 seconds for the screenshot run. Desktop fixtures drain the reader before removing their profiles. Screenshot staging stays inside the parent-owned temporary directory. If replacing a complete screenshot set fails and rollback also fails, the previous set remains outside that directory and the error names its location. Keep the current screenshot set, latest useful failure evidence and incremental caches.

Measure with `/usr/bin/time -p` around the commands above. Report the first build of restored targets separately from an unchanged build. A dependency recipe or patch change currently invalidates the complete dependency set; application-only changes reuse it. Do not compare different test inventories or SDKs as a measured speedup. Linux execution has not yet been validated with a matching prepared SDK; the test sources and cleanup launcher avoid Mac-only test logic where possible.
